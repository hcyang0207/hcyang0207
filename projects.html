IoT平台 IoT 雲端管理平台

CUMI IoT 平台

專為大專院校、中小學與公家機關打造的智慧聯網監控與設備管理平台

整合校園與機關場域內的各類環境感測器、電力監控與智慧控制設備。透過高可靠度的 MQTT 通訊架構與雲端後台，提供即時數據視覺化儀表板、設備狀態追蹤、異常告警通報與排程自動化管理，大幅提升公部門與校園場域的智慧化維運效率。

  • 物聯網雙向架構：支援多類微控制器與感測模組透過 MQTT / HTTP 安全上雲。
  • 機構級權限控管：以 Laravel 建構多層級單位、場域與設備讀寫權限管理。
  • 即時告警與自動化：可自訂感測閾值觸發即時通知與遠端繼電器排程控制。

IoT平台 軟硬體整合・跨國智慧水務

Pureten 智慧水表平台

硬體電路設計、Layout、成品製作到雲端平台軟硬體全棧整合實績（菲律賓跨國加水站）

專為菲律賓連鎖加水站量身打造之跨國商用物聯網系統。從硬體端「電路原理圖設計」、「PCB Layout 洗板佈線」、「實體硬體焊接與成品製作」，到微控制器韌體開發、斷線續傳、流量計脈衝採樣，並全面打通後端 PHP / Laravel 雲端帳務管理、即時出水量監控、濾心耗材壽命預警與多據點連鎖營運平台，實現真正的 IoT 軟硬體一條龍自主研發與跨國商業落地。

  • 全自主硬體研發與製作：自主完成智慧水表專用電路設計、PCB Layout、打樣焊接與實體設備封裝成品。
  • 軟硬整合與高可靠韌體：因應海外不穩定網路環境，設計流量脈衝精確計量、斷線本地快取與自動續傳重試機制。
  • 智慧水務預警與連鎖雲端管理：自動累計各站點出水量、推算濾心維護週期，並整合跨國多站點帳務對帳與設備權限。

Gmail Notes

專為 Gmail 打造的高效信件備註與資訊標記瀏覽器擴充套件（Browser Extension）

解決大量商務與專案信件往來時的上下文記憶痛點，讓使用者能直接在 Gmail 介面中針對個別郵件快速新增、編輯與檢視私人備註與摘要標籤。無縫融入原生信箱操作體驗，大幅提升日常郵件管理與專案追蹤效率。

  • 原生級 Gmail DOM 整合：直覺嵌入信件列表與內頁，操作流暢不干擾既有介面。
  • 即時備註與標籤檢索：一眼識別重要客戶來信背景、待辦事項與專案進度。
  • 輕量化與隱私優先：極速載入架構，專為重度郵件工作者打造的高效工具。
