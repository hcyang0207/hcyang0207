精首先天智能皮紋採集系統

Dermatoglyphics System 專為指紋與先天智能皮紋高精度數位化採樣所建構之專用桌面端應用軟體。本頁提供主程式最新安裝檔、FM220U 光學感測器驅動程式與完整的影音教學指引。

💡

安裝前重要提示

請先安裝 FM220U 指紋機驅動程式，再進行 Dermatoglyphics 主程式 安裝。若於 Windows 11 下載或執行時出現安全警告阻擋，請參考下方第 5 部影音教學進行解除防護設定。
